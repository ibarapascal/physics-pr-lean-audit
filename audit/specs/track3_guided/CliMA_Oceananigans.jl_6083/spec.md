## 1. What changed

PR #6083, **“Include drift velocities in the implicit part of adaptive implicit tracer advection”**, merged as `1734ff9e4509198f945c5e7740a0bccacc69a720` (base `e3ff915746b71fe9d78840d7c0d2bb20e4359b37`). This specification uses the supplied diff and commit-pinned source, not the PR description alone. Numerical checks below are proposed, not executed.

* `src/Models/HydrostaticFreeSurfaceModels/hydrostatic_free_surface_tendency_kernel_functions.jl`: extracts `tracer_advecting_velocities`. For tracer q it assembles
  \[
  \mathbf U_q=\mathbf U_{transport}+\mathbf U_{bio,q}+\mathbf U_{closure,q}
                 +\sum_r\mathbf U_{advective\ forcing,r,q}.
  \]
  The explicit `hydrostatic_free_surface_tracer_tendency` uses this helper. Ordinary source forcing is not an advecting velocity.
* `src/Models/HydrostaticFreeSurfaceModels/hydrostatic_free_surface_ab2_step.jl`, `ab2_step_tracer!`, and `hydrostatic_free_surface_rk_step.jl`, `rk_substep_tracer!`: pass that same assembled velocity to `implicit_step!`, replacing transport velocity alone. The existing adaptive split is, at a tracer face,
  \[
  C=|W_q|\Delta\tau/\Delta z_f,\quad
  s=\begin{cases}1&C\le C_*\\C_*/C&C>C_*\end{cases},\quad
  W^e=sW_q,\quad W^i=(1-s)W_q.
  \]
  Here \(\Delta\tau\) is the scheme's relevant stage interval, not necessarily the whole RK step. Explicit reconstruction and implicit first-order upwind reconstruction differ: this is a velocity decomposition, not an assertion that their instantaneous tracer fluxes are identical.
* `src/TurbulenceClosures/turbulence_closure_implementations/advective_skew_diffusion.jl`: introduces `isopycnal_slope`, six buoyancy-gradient interpolation helpers at `(Face, Center, Face)` and `(Center, Face, Face)`, and revises `ϵSxᶠᶜᶠ`, `ϵSyᶜᶠᶠ`, their κ-weighted wrappers, and `_compute_eddy_velocities!`. Previously each component used its own scalar slope for tapering and did not use the tensor's stratification floor. Now each location uses both horizontal components and the same floor/taper convention as `calc_tapering`. Writing \(m=\mathrm{FT}(minimum\_bz)\), \(B=\max(b_z,m)\), and \(g_h=\partial_h z|_r\),
  \[
  S_h=\begin{cases}-b_h/B+g_h&B>0\\g_h&B\le0\end{cases},\qquad
  \epsilon=\begin{cases}\min(1,S_m^2/(S_x^2+S_y^2))&B>0\\0&B\le0.\end{cases}
  \]
  For \(B>0,S_x=S_y=0,S_m>0\), the floating-point expression evaluates to 1. Streamfunction components are \(P_x=\kappa_{skew}\epsilon S_x\), \(P_y=\kappa_{skew}\epsilon S_y\), set to zero on their respective peripheral nodes. The existing curl construction remains
  \[
  u_e=-\partial_zP_x,\quad v_e=-\partial_zP_y,\quad
  w_e=\partial_xP_x+\partial_yP_y,
  \]
  with staggered differences and horizontal face metrics in the actual kernel. Untapered `Sxᶠᶜᶠ`/`Syᶜᶠᶠ` retain their old formulas; their changes are cleanup/comment corrections.
* `src/TurbulenceClosures/turbulence_closure_implementations/isopycnal_skew_symmetric_diffusivity.jl`, `calc_tapering`: converts both `max_slope` and `minimum_bz` to the grid float type before arithmetic. This affects tapering in both advective and diffusive formulations. `isopycnal_slope` likewise converts the floor, addressing mixed Float32-grid/Float64-parameter kernel inference.
* `src/Operators/derivative_operators.jl` adds zero defaults for `∂x_zᶜᶠᶠ` and `∂y_zᶠᶜᶠ`. `src/ImmersedBoundaries/mutable_immersed_grid.jl` specializes them to staggered finite differences of `znode` divided by horizontal spacing for mutable grids, including mutable immersed grids. `src/TurbulenceClosures/TurbulenceClosures.jl` imports the new operators.
* `test/unit/adaptive_implicit_vertical_advection.jl` adds a biogeochemical sinking-tracer regression for both changed hydrostatic timesteppers.

## 2. Invariants

**I1 — Complete tracer velocity and transport rate (primary).** For a fixed tracer, stage, geometry, and supplied velocity fields, the explicit and implicit pieces must split the same total \(W_q\): \(W^e+W^i=W_q\), \(|W^e|\Delta\tau/\Delta z_f\le C_*\), with \(W^i=0\) below and at the threshold. Redistributing an identical prescribed total velocity among supported additive sources must leave the tracer update unchanged up to rounding, provided all source fields have identical stage histories and no extra reactions/diffusion are introduced. Opposite contributions must cancel before computing the CFL. For constant vertical velocity and a localized tracer isolated from boundaries, the continuum consequence is
\[
\bar z(t)-\bar z(0)=W_qt,\qquad \bar z=\frac{\int zq\,dV}{\int q\,dV}.
\]
A finite-grid check of this last statement allows truncation and boundary-tail errors. Domain: finite velocities, positive cell thickness, \(\Delta\tau>0,C_*>0\), supported adaptive tracer schemes and the two changed hydrostatic timesteppers. Moving-grid splitting must use the same pre-update thickness; the implicit implementation explicitly reconstructs previous thickness. This PR does not fix or establish analogous behavior in other model families.

**I2 — Conservative tracer inventory (primary).** With no reactions, external tracer sources, or boundary tracer flux,
\[
M^{n+1}=M^n,\qquad M^n=\sum_{\text{wet cells }a}V_a^nq_a^n.
\]
More generally inventory changes by the time-discretized external flux/source budget. This holds for divergent particle drift too; a spatially constant concentration need not remain constant under divergent drift. Domain: closed or periodic boundaries, consistent wet-cell volumes and shared numerical face fluxes; use time-dependent volumes on moving grids. Neither exact tracer variance conservation nor positivity of arbitrary WENO/AB2 combinations is required here.

**I3 — Joint, direction-independent GM taper and stratification convention (primary).** At each individual streamfunction location, for \(B>0\), finite slopes, and \(S_m>0\), the taper must obey the formula in section 1, \(0\le\epsilon\le1\), and
\[
\|\epsilon\mathbf S\|_2\le S_m,\qquad
\epsilon(Q\mathbf S)Q\mathbf S=Q\epsilon(\mathbf S)\mathbf S
\]
for horizontal orthogonal transformations \(Q\). On a Cartesian discrete grid, exact covariance is required for axis exchange/sign reflection on correspondingly transformed grids; arbitrary-angle covariance is a continuum/local algebra property, not exact rotational invariance of a finite stencil. Both slopes must be collocated before taking the norm. For \(B\le0\), tapered components are zero; peripheral components are zero regardless of stratification. Positive `minimum_bz` means **floor first**, so even raw \(b_z<0\) gives \(B>0\) and does not necessarily switch transport off. This is a library modeling convention, not a universal convective-mixing law. The default is `minimum_bz=0`, `max_slope=0.01`. Zero/negative maximum slope, NaNs, and overflowing inputs are excluded.

**I4 — GM nondivergent transport and impermeable boundaries.** For smooth Cartesian continuum fields, \(\nabla\cdot\mathbf U_e=0\) by cancellation of mixed derivatives. On a fixed Cartesian finite-volume grid the corresponding requirement is
\[
\sum_{f\in\partial a}\operatorname{orientation}(a,f)A_f U_{e,f}=0
\]
for each active cell, and zero normal eddy flux through closed boundaries when the peripheral streamfunction condition applies. With prescribed stationary eddy transport, constant tracer is therefore a steady solution; inventory obeys I2. Domain: compatible discrete curl/divergence metrics and masks. Exact cancellation on mutable/partial-cell geometries is a separate compatibility check, not assumed from Cartesian calculus. With pure skew flux, advective and diffusive formulations represent the same continuum tracer tendency; their different staggerings/tapers need only converge to it, not coincide pointwise at finite resolution.

**I5 — Geometric slope consistency.** If \(b_h\) is differentiated at fixed computational coordinate \(r\), then, where \(b_z>0\) and the floor is inactive,
\[
-\frac{\partial_hb|_r}{\partial_zb}+\partial_hz|_r
=-\frac{\partial_hb|_z}{\partial_zb}.
\]
Thus a physically horizontal buoyancy field \(b=N^2z+b_0\), \(N^2>0\), produces zero physical isopycnal slope and no GM transport even on tilted coordinate surfaces. New cross-staggered geometric derivatives must be zero on a fixed horizontal grid and reproduce affine coordinate slopes on a mutable grid, up to roundoff. Smooth non-affine cases require consistency under refinement. Domain: nonsingular positive-thickness coordinates, interior wet stencils; an active stratification floor can break this chain-rule interpretation and is outside this geometric invariant.

**I6 — Precision/backend consistency of these physical results.** Finite representable inputs in the above domain must produce finite outputs and execute on CPU and supported CUDA devices. Float32-grid runs with default Float64 floor/limiter parameters must approximate the same I1–I5 results as Float64 runs after accounting for conversion and rounding. This is a numerical realization requirement, not an additional physical law. It does not require bitwise CPU/GPU identity or that every intermediate expression in the entire closure be Float32.

## 3. Sources of the invariants

* I1 follows from the conservative tracer equation \(\partial_tq+\nabla\cdot(\mathbf U_qq)=0\), the first-moment balance, and the library's complementary split. See the commit-pinned [explicit adaptive flux](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/Advection/adaptive_implicit_vertical_advection.jl), [implicit upwind coefficients and previous-thickness rule](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/Advection/implicit_vertical_advection.jl), and [additive AdvectiveForcing interface](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/Forcings/advective_forcing.jl).
* I2 is finite-volume flux telescoping, with the Reynolds transport theorem for moving cells. It is independent of the scientific origin of a velocity contribution.
* I3 is the library's stated Gerdes–Koberle–Willebrand (1991), *Climate Dynamics* 5, 211–226 taper convention, as documented in [the closure](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/TurbulenceClosures/turbulence_closure_implementations/isopycnal_skew_symmetric_diffusivity.jl). The same docstring cites Gent and McWilliams (1990) and Redi (1982) for the mesoscale parameterization. These attributions are from the source; no claim of independently verifying the papers' full implementations is made. The norm bound and covariance follow algebraically from the radial taper.
* I4 follows from divergence of a curl and the skew-flux identity, with the signs fixed by [the eddy-velocity kernel](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/TurbulenceClosures/turbulence_closure_implementations/advective_skew_diffusion.jl). I5 follows from the coordinate chain rule and [mutable-grid derivative definitions](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/ImmersedBoundaries/mutable_immersed_grid.jl).
* The [small-slope tensor docstring](https://github.com/CliMA/Oceananigans.jl/blob/1734ff9e4509198f945c5e7740a0bccacc69a720/src/TurbulenceClosures/isopycnal_rotation_tensor_components.jl) says stable stratification has \(\partial_zb<0\). That sign is inconsistent with upward z, conventional buoyancy, and the implementation's positive-stratification branch. This specification uses \(b=N^2z\), \(N^2>0\), as stable. Choices of positive stratification floor, taper strength, and small-slope approximation are modeling choices; the PR is judged against the explicit library convention, not an inferred requirement to disable all negative raw stratification.
* I6 follows from the intended type conversions and numerical consistency across supported architectures; no external standard supplies a universal tolerance.

## 5. Numerical check plan

Use public constructors, `set!`, `time_step!`, `Simulation`/`run!`, and `Array(interior(field))`. `set!(model; ...)` refreshes closure fields at this commit; inspect `model.closure_fields.u/v/w` after it. Do not call the modified private slope kernels as the primary oracle. Independent finite-volume differences of exposed fields and grid-node coordinates provide diagnostics. For normalized fields use roundoff tolerances \(T_{64}=10^{-11}\), \(T_{32}=5\times10^{-5}\) over short runs (at most 20 steps); use scale-aware absolute tolerance \(T\max(1,\|q_0\|_\infty)\). Accumulate inventories on the host in Float64. All stated tolerances are acceptance criteria to be verified, not measured results.

**I1 and I2: transport-source matrix.** Start with the added test's exact public setup: `RectilinearGrid(arch, FT; size=40, z=(-400,0), topology=(Flat,Flat,Bounded))`, `ZFaceField`, `WENO(FT; order=5, time_discretization=AdaptiveVerticallyImplicitDiscretization(FT; cfl=0.5))`, and `HydrostaticFreeSurfaceModel(...; momentum_advection=nothing, free_surface=nothing, timestepper=...)`. Implement the documented `AbstractBiogeochemistry` extension used in the test (`required_biogeochemical_tracers`, `biogeochemical_drift_velocity`, and `Adapt.adapt_structure`), returning zero horizontal fields and a vertical field zero at top/bottom. Initialize \(D=\exp[-(z+100)^2/800]\); take three 0.4-day steps at -100 m/day. Check relative inventory error below T and descent within 5% of 120 m. Mirror the profile and velocity to check upward transport. For a stronger centroid test enlarge the domain until boundary-tail influence is below 0.1% and repeat at 40/80/160 cells, controlling CFL. Do not require exact translated profile: the implicit upwind component is diffusive.

Repeat for both `:QuasiAdamsBashforth2` and `:SplitRungeKutta3`, both precisions/backends, zero speed, and stage CFL ratios \(C/C_*\in\{0,0.1,0.99,1,1.01,2,8\}\). Account for each RK substep when choosing Δt. Compare adaptive and `ExplicitTimeDiscretization()` updates below every stage threshold at tolerance T. Cover `WENO(order=5)`, `UpwindBiased(order=1)`, and `Centered(order=2)` at conservative explicit CFL; use the upwind case to compare a separately assembled conservative tridiagonal update, removing centroid truncation ambiguity. Do not impose positivity on the centered case.

Exercise each contributing group: biogeochemistry alone; `forcing=(D=AdvectiveForcing(w=W),)` alone; two additive advective forcings in the supported forcing tuple, including an ordinary zero `Forcing`; transport alone in a multidimensional divergence-free circulation; GM closure alone; and combined sources. A one-column hydrostatic model cannot prescribe an independent uniform transport w consistently with closed boundaries: use a resolved two-dimensional cellular circulation initialized via public `set!(model; u=...)` and its diagnosed w for that branch. For equal-total comparisons, use identical model dynamics and move prescribed arrays between biogeochemical drift and forcing. Compare complete tracer arrays at T, not just moments. Add opposite drifts that cancel exactly, and totals just on either side of the threshold; add two tracers with different drift/forcing assignments to detect incorrect tracer lookup.

For the actual closure source, build `IsopycnalSkewSymmetricDiffusivity(; κ_skew=1000, κ_symmetric=nothing, skew_flux_formulation=AdvectiveFormulation())` with `BuoyancyTracer()` and tracers `(:b,:D)`. Use spatially varying b producing nonzero wₑ. Compare short-step D tendencies with an otherwise matched model supplying the observed eddy fields through `AdvectiveForcing`; halve Δt and require the difference divided by Δt to converge to zero (closure evolution prevents exact equality over a finite interval). Include nonzero background transport, drift and forcing together and compare with a resolved small-step reference. Test closure `nothing`, κ_skew=`nothing`, scalar zero κ, a single GM closure, and closure tuples of lengths 1–4 plus 5, with the one GM closure moved through every position and remaining closures having zero coefficients. Multiple simultaneous GM closures are outside the existing tuple-selection contract.

Apply I2 to every run, using actual wet-cell volumes rather than unweighted sums on stretched/mutable grids. Add a stretched vertical grid and an `ImmersedBoundaryGrid(..., GridFittedBottom(...))`; ensure all added velocities have zero normal flux at solid faces. For moving volumes use `MutableVerticalDiscretization`, `ZStarCoordinate()`, `ImplicitFreeSurface()`, and `set!(model; η=...)`, reading current coordinates after each step. Require \(|M_n-M_0|/\sum V_0|q_0|<T\); separate any imposed boundary/source budget before testing.

**I3: manufacture the eddy streamfunction through the closure API.** On a 16×16×32 bounded Cartesian grid initialize linear \(b=N^2(z-S_xx-S_yy)\), excluding boundary stencils from the interior slope comparison. Use `SmallSlopeIsopycnalTensor(; minimum_bz=m)` and `FluxTapering(S_m)` with `AdvectiveFormulation()`. Take κ as a positive linear function of z, accepted as `(x,y,z,t)->...`. In the interior this yields the diagnostic \(u_e=-\kappa'(z)\epsilon S_x\), \(v_e=-\kappa'(z)\epsilon S_y\): constant κ and constant slopes alone would yield zero velocity and fail to expose a wrong taper. Compare against an independent piecewise formula at relative tolerance T (absolute tolerance T times the characteristic nonzero velocity for zero branches).

Sweep all slope norm ratios, quadrants, floor cases, and both streamfunction staggerings listed in section 4. In particular use \(S_x=S_y=0.8S_m\): each individual component is below the cap but the joint norm is above it. Exchange x/y grid dimensions and gradients and check exchange of u/v, preservation of w, and both sign reflections. Check norm bounds on the inferred tapered slopes. For a 3-D variable-gradient case independently interpolate raw buoyancy differences to each of the two staggerings before applying the formula. Repeat with constant, callable, and face-field κ representations. Check both `AdvectiveFormulation()` and `DiffusiveFormulation()` for the shared taper, with `ExplicitTimeDiscretization()` and `VerticallyImplicitTimeDiscretization()` closure options; for the diffusive formulation compare short-time tracer tendencies to an independently assembled staggered flux, rather than expecting eddy fields to exist. Include κ_symmetric absent and positive, and scalar versus per-tracer symmetric coefficients. Per-tracer skew NamedTuples are rejected for the advective formulation and should remain rejected.

**I4: divergence and boundary budget.** Initialize smooth periodic horizontal buoyancy variations and stable vertical stratification, with variable κ, through the same closure constructors. Read all three eddy-velocity fields; sum signed face transports for each cell. Require residual \(|\sum_f A_fU_f|\le T\max_a\sum_{f\in\partial a}|A_fU_f|\), using an absolute roundoff scale for the all-zero case. Separately check top/bottom and bounded side fluxes and repeat at immersed peripheries. Test x–z, y–z and full 3-D configurations, uniform and stretched z, and the mutable configuration; report geometric failures separately. Evolve a constant passive D using stationary prescribed copies of these velocities, checking constancy and I2 at T. With smooth pure-skew manufactured fields compare the advective and diffusive short-time tendencies at 16³, 32³ and 64³: require error to decrease on both refinements and reach below 2% of a nonzero analytic tendency norm. Use small Δt and untapered or spatially smooth tapered branches so a limiter kink does not masquerade as failure of continuum equivalence.

**I5: coordinate manufactured solutions.** Construct mutable and fixed versions of the same domain, including a grid-fitted bottom. Set small x-only, y-only and combined free-surface slopes via `set!(model; η=...)`; after coordinates refresh, initialize b arrays from their physical cell-center z values to represent \(b=N^2z\). The inferred slopes/eddy velocities must vanish at the above scale-aware tolerance on affine interior stencils; for smooth varying geometry require convergence to zero under refinement. Then initialize a physical affine tilted buoyancy field and compare the inferred taper/velocity to its known physical slope using variable κ as in I3. This exercises both new cross-staggered coordinate derivatives through the public closure path, including the generic zero fallback, mutable unimmersed specialization and mutable immersed specialization. Exclude wet/dry interface stencils from affine-exactness assertions but test their boundary flux under I4.

**I6: backend/precision matrix.** Run all small algebraic/manufactured cases on CPU and CUDA in both precisions, explicitly retaining Float64 `FluxTapering` and `SmallSlopeIsopycnalTensor` defaults on Float32 grids, then repeat with Float32 parameters. Check successful kernel compilation, all outputs finite, parameter-converted reference agreement, and CPU/GPU agreement at T. Use `Array(interior(...))` to synchronize and compare. For refinement tests stop before Float32 cancellation dominates; use Float64 for asymptotic accuracy judgments. No private function's inferred return type alone constitutes a physics test.

## 7. Expected verdict

* **I1: expected pass for static, supported hydrostatic configurations.** Both callers now use the same helper as the explicit tendency, directly repairing omission of drift/forcing/closure velocity. Exact source equivalence requires matched stage histories. Moving-coordinate and evolving-closure combinations remain **uncertain until checked**, because sharing assembly code alone does not establish time/geometry consistency.
* **I2: expected pass** for the closed fixed-grid regression and standard conservative configurations: the change alters velocity coefficients, not the flux-divergence structure. Mutable and immersed volume-budget combinations are **unverified**.
* **I3: expected pass** for finite supported parameters. The new collocated joint norm removes componentwise orientation dependence; floor and peripheral behavior match the formulas stated here. A demand that every negative raw b_z disable GM even with a positive floor would fail, but that is not the implemented convention.
* **I4: expected pass on fixed Cartesian compatible grids**, by the discrete curl structure. Boundary masks, mutable metrics and finite-grid advective/diffusive agreement are **uncertain**; only convergence, not exact finite-grid equality, is expected for the latter.
* **I5: expected pass for affine interior geometry with inactive floor**, because the missing derivatives now differentiate actual node coordinates at the required staggerings. Non-affine mutable/immersed accuracy is **uncertain until manufactured-solution checks**.
* **I6: expected improvement and likely pass for the targeted Float32 advective-GM CUDA case**, because limiter/floor conversions remove the reported union-valued branch. This is not a verified GPU result; the broader diffusive closure and all mixed-type coefficient representations remain **uncertain**.

## 9. Formalization feasibility

I1's complementary split and CFL bound are straightforward real-arithmetic case proofs for positive Δz, Δτ and C*. Proving source completeness additionally requires transcribing the velocity-sum/forcing dispatch, tracer lookup, and both timestep call paths. A proof over the local scalar split alone would miss precisely the original caller bug. Centroid transport requires a conservation/moment theorem and explicit boundary assumptions; finite-step truncation bounds are substantially harder.

I2 can be proved by cancellation of shared finite-volume face fluxes, and conservation of the implicit matrix solve by a volume-weighted left-vector identity. One must transcribe the actual timestep coefficients, boundary rows, wet-cell masks and moving-cell volume update. Floating-point solver error is a separate bound.

I3's piecewise taper, norm bound and orthogonal covariance are suitable for Lean over real vectors, with a defined zero-slope branch and parameter-conversion abstraction. Actual Julia `ifelse` eagerly evaluates divisions even when the selected branch is zero; IEEE infinities/NaNs, signed zero and conversion rounding cannot be modeled by Lean's totalized real division alone. Defaults with S_m>0 avoid the undefined 0/0 taper limit as an output, but a faithful implementation proof still needs IEEE semantics.

I4 is a finite-dimensional incidence/metric identity on a fixed compatible grid, or a mixed-derivative theorem in the continuum. Peripheral masks, staggerings and mutable metric compatibility are the main discrete obstacles. I5 is a chain-rule proof plus finite-difference affine exactness; convergence on non-affine moving coordinates requires interpolation and mesh-regularity estimates. I6 cannot be established by a real-valued transcription alone: it requires floating-point error analysis and a trusted account of Julia specialization, GPU compilation and kernel execution. The most practical formal target is the scalar split/taper algebra plus a fixed-grid conservative stencil; full backend correctness is a separate project.
