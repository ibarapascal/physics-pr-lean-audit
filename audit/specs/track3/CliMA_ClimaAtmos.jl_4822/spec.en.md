## CliMA/ClimaAtmos.jl#4822 Compute horizontal gradient along isentropes in SGS variance

- What changed (1–3 sentences, naming files and formulas):
  `src/parameterized_tendencies/microphysics/cloud_fraction.jl` replaces independent horizontal temperature/moisture gradient variances and their cross term with a moisture-only contribution `H = c_g c_x² Δx² f |b − (v/d)a|²`, where `d = max(u, θ_min)` and `f = [1 + |a|² Δx²/(d² Δz²)]⁻¹`. It also multiplies the vertical moisture variance and θ–q covariance by `f`, leaving vertical θ variance unchanged; `src/parameters/{Parameters,create_parameters}.jl` introduces the provisional floor `θ_min = 10⁻³ K m⁻¹`, with documentation/configuration descriptions and scalar tests updated. The horizontal term is off by default (`c_x = 0`), in which case the implementation sets `f = 1` for the vertical block.

- Invariants (mathematical statements; write them as checkable equalities/inequalities, give variables, sign conventions, domain of validity):

  Use local Cartesian physical coordinates with `z` increasing upward, `θ = θ_li` in K, and `q = q_tot` as specific humidity in kg/kg. Define horizontal vectors `a = ∇_h θ`, `b = ∇_h q`, vertical derivatives `u = ∂z θ`, `v = ∂z q`, grid lengths `Δx, Δz > 0`, nonnegative dimensionless coefficients `c_g, c_x, c_z`, positive floor `θ_min`, `d = max(u, θ_min)`, `r = v/d`, `s² = |a|²/d²`, and `ℓ² = Δx² f`. Statements about exact isentropes require `u ≥ θ_min`; below the floor the library uses an explicitly regularized stable-slope model, not the true isentrope of an overturned layer. All covariance identities below refer to the closure's θ basis before its scalar θ→T transform, unless specified otherwise.

  **I1 — Primary: moisture contrast follows the isentrope and does not create θ fluctuations.** For an affine local field with `u ≥ θ_min`, a horizontal displacement `δx` has `δz = −a·δx/u` on the θ surface. Consequently `δθ = 0`, `δq = (b − (v/u)a)·δx`. For the modeled horizontal displacement covariance `E[δx δxᵀ] = c_g c_x² ℓ² I`, require
  
  `V_q,h = c_g c_x² ℓ² |b − (v/u)a|² ≥ 0`, `V_θ,h = 0`, `C_θq,h = 0`.
  
  In particular, for `q = Aθ + B` with constant A and B, `b = Aa`, `v = Au`, so `V_q,h = 0`, including either sign of A. Orthogonal rotation of both horizontal vectors must leave `V_q,h` unchanged. Below the floor check the declared regularized formula and `|r| ≤ |v|/θ_min`, not exact isentropic cancellation. A negative vertical moisture gradient changes whether aligned horizontal gradients amplify or cancel; the sign is determined by `r`, not by alignment alone.

  **I2 — Secondary: cell-limited excursions yield realizable covariance blocks.** For finite inputs in the range below,
  
  `0 < f ≤ 1`, `0 < ℓ² ≤ Δx²`, `s²ℓ² ≤ Δz²`, and `s²ℓ² + fΔz² = Δz²`.
  
  The vertical block, with `G = c_g(c_z Δz)²`, must be
  
  `Σ_v = G [[u², fuv], [fuv, fv²]]`,
  
  with nonnegative diagonal entries and `det Σ_v = G² u²v² f(1−f) ≥ 0`. Adding the horizontal block `diag(0,H)` and any positive-semidefinite turbulent block must preserve positive semidefiniteness: `C_θq² ≤ V_θ V_q`. For `b = 0` and `c_x = c_z = 1`, the shared-excursion identity gives the particularly useful moisture budget `H + Gfv² = c_g Δz²v²`, independent of surface slope, including the floored-slope regime. For `a = 0`, `f = 1` and the vertical block reduces to the ordinary affine uniform-box covariance (with `c_g = 1/12`, `c_z = 1`).
  
  The library's scalar Jacobian `J = ∂T/∂θ` gives `V_T = J² V_θ`, `C_Tq = J C_θq`; this congruence transform must preserve the covariance inequality. If the moisture bound is active, `k = min(1, r_max q/sqrt(V_q))`, then away from numerical floors the intended scaling is `V_q → k²V_q`, `C_Tq → k C_Tq`, preserving correlation for `k > 0`. This is a realizability check on the implemented closure, not a claim that a full moist thermodynamic Jacobian has no q dependence.

  **I3 — Primary: continuously removing horizontal stirring must recover the vertical-only closure.** Hold state, grid, positive `c_z`, and all other parameters fixed; let the horizontal length multiplier `c_x = ε → 0⁺`. In a laminar affine cell with inactive moisture limiter, require
  
  `lim[ε→0⁺] V_q(ε) = V_q(0)`, `lim[ε→0⁺] C_θq(ε) = C_θq(0)`.
  
  The physical requirement is that an arbitrarily small along-surface sampling amplitude cannot remove a finite vertical moisture excursion. This is a proposed closure consistency invariant, not an assertion that the PR promises an exact uniform physical-cell PDF for every sloped field. A revealing case is `b = 0`, `v ≠ 0`, `u > θ_min`, `sΔx/Δz = 1`: with turbulence absent, the off value is `c_g c_z² Δz²v²`. Any finite jump as ε tends to zero violates the proposed invariant even if all variances remain nonnegative.

- Formalization (Lean) feasibility: can the invariant be written as a proposition over finite-dimensional reals, and what are the main obstacles:

  Yes. I1 is an identity for vectors in R² and affine functions on R³; expanding a squared norm proves positivity and cancellation. I2 is rational algebra after replacing s² by `|a|²/d²`, followed by a 2×2 positive-semidefinite matrix argument and congruence/scaling; positivity of d and the grid lengths discharges denominator conditions. I3 is a one-sided real limit of a piecewise rational expression and can be proved or refuted independently of atmospheric dynamics. The main obstacles are bridging these real-valued propositions to floating-point code, modeling max/clamp/fallback boundaries, proving the horizontal filter preserves the required Gram-matrix properties, and connecting physical gradients, thermodynamic initialization and the public diagnostics to the abstract affine-field assumptions. Proving these algebraic invariants cannot by itself establish empirical adequacy of the isentropic closure in neutral or overturned layers.
