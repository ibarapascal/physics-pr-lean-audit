## CliMA/Oceananigans.jl#6024 Fix CATKE's bottom mixing length coefficient Cᵇ

- What changed (1–3 sentences, naming files and formulas):
  `src/TurbulenceClosures/turbulence_closure_implementations/TKEBasedVerticalDiffusivities/catke_mixing_length.jl` changes the default bottom boundary coefficient `Cᵇ` from `0.28` to `0.967`, and adds a description of the neutral similarity-layer relation κ = C[(Cˡᵒu)³/CˡᵒD]^(1/4); `docs/src/models/turbulence_closures.md` is updated with the displayed value. This change does not alter any discrete operator or add tests. The following are conditional closure-model invariants, not universal conservation laws for arbitrary ocean currents.

- Invariants (mathematical statements; write them as checkable equalities/inequalities, give variables, sign conventions, domain of validity):
  Conventions: z points upward, flat bottom at z = −H, resting surface at z = 0, d = z + H > 0; e is the TKE per unit mass (m²/s²), b is buoyancy, N² = ∂b/∂z, S = ∂U/∂z > 0. Let a = Cˡᵒu = 0.361, q = Cˡᵒc = 0.369, r = Cˡᵒe = 7.863, D = CˡᵒD = 1.604, B = Cᵇ = 0.967, A = Cˢ = 1.131. ν, Kc, Ke are the vertical diffusivities of momentum, of an ordinary tracer and of TKE respectively; ε ≥ 0 is the dissipation rate, which contributes −ε in the TKE equation.

  1. **Primary — κ calibration of the bottom neutral equilibrium layer.** In a local similarity layer with N² = 0, no convection, dominated by the bottom-distance limit, with e above the numerical floor and no diffusivity truncation, ℓ = Bd, ν = aℓ√e, ε = D e^(3/2)/ℓ. If the shear production P = νS² balances ε, and the positive kinematic stress magnitude is u★² = νS, then we must have
     e = u★²/√(aD), κ_eff = B(a³/D)^(1/4), ν = κ_eff u★d, S = u★/(κ_eff d).
     Hence κ_eff⁴D = B⁴a³, and the default parameters should satisfy |κ_eff − 0.4| ≤ 5×10⁻⁴. The last tolerance allows B to keep only three decimals; κ_eff must not be required to equal the decimal 0.4 strictly in floating point. The corresponding continuous velocity difference is U(d₂) − U(d₁) = (u★/κ_eff) log(d₂/d₁), but the whole finite water column or the bottom-most grid cell is not required here to obey the logarithmic law strictly.

  2. **Secondary — distance law, proportions and nonnegativity of neutral bottom mixing.** With uniform positive e, N² = 0, zero surface buoyancy flux, and neither the H length cap nor the diffusivity cap triggered, in the bottom-controlled region
     (ν, Kc, Ke) = Bd√e (a, q, r), ν ≥ 0, Kc/ν = q/a, Ke/ν = r/a.
     For any two interior faces d₁,d₂, if both are on this branch, ν(d₂)/ν(d₁) = d₂/d₁. In two configurations B₁, B₂ with fixed e, if both are bottom-controlled, ν₂/ν₁ = Kc₂/Kc₁ = Ke₂/Ke₁ = B₂/B₁; in particular the ratio of the new to the old default coefficient is 0.967/0.28. The reference formula for a general neutral water column is Kα = √e min[H, cα min(Bd,A(H−d))], cα ∈ {a,q,r}, with the corresponding maximum-diffusivity cap applied in addition. This general formula explains why Ke may saturate first at larger distances from the bottom, where the three coefficients must not be forced to change proportionally. The boundary faces are explicitly set to zero by the implementation and are not used in the interior-face proportion test.

  3. **Secondary — the same bottom length must consistently control TKE dissipation.** In a water column with N² = 0, no shear, no surface forcing, and initially uniform e₀ > minimum_tke, the initial TKE diffusion is zero. For interior cell centers that are bottom-controlled with ℓ/D < H:
     ε(d) = D e₀^(3/2)/(Bd) > 0, lim(Δt→0⁺)[e(d,Δt)−e₀]/Δt = −ε(d).
     For fixed e₀, d, ε(B₂)/ε(B₁) = B₁/B₂. Therefore increasing the same B both increases the eddy viscosity at a given TKE and reduces the local dissipation at a given TKE; "enhanced bottom drag" must not be understood as every post-feedback flow regime having the same response.

- Common operating domain (range of each input, with the basis):
  The mathematical domain is H > 0, 0 < d < H, B,a,D > 0, finite e > minimum_tke, and Bd < A(H−d). When the three diffusivities are checked together, rBd < H is also required; immersed boundaries, wet–dry cells, wave forcing, rotation, advection and other superposed closures are excluded. N² is set to exactly zero, and the surface buoyancy and momentum fluxes are set to zero; a slightly negative N² must not be used in place of zero, because a negative Ri uses different stability coefficients.
  Suggested random samples: H ∈ [10,1000] m; interior sampling d/H ∈ [0.01,0.05]; e₀ ∈ [10⁻⁶,10⁻²] m²/s²; for B tests use the old value 0.28, the new value 0.967, or random values in [0.2,1.2]. These are audit ranges that make it convenient to isolate branches and avoid the default e floor of 10⁻⁹, not an applicability range claimed in the literature. For the first item take u★ ∈ [10⁻³,10⁻¹] m/s and generate e from the balance formula; the reference constant of U can be zero. The similarity law is used only in the turbulent region away from the viscous/roughness sublayer; this closure does not resolve the molecular viscous sublayer. For a uniform grid Nz ≥ 512 is suggested, excluding difference stencils that touch the physical boundary; all comparisons use the true grid coordinates.

- Numerical check method (which public API of the merged commit, what to compute, what to compare against, suggested tolerance and why; if finite differences are needed, the step-size strategy):
  **Public entry points and observables.** Use `using Oceananigans`, and import `CATKEVerticalDiffusivity`, `viscosity`, `diffusivity` from `Oceananigans.TurbulenceClosures`. Build `RectilinearGrid(CPU(), Float64; size=Nz, z=(-H,0), topology=(Flat,Flat,Bounded))`, then build `HydrostaticFreeSurfaceModel(grid; closure=CATKEVerticalDiffusivity(Float64), buoyancy=BuoyancyTracer(), tracers=(:b,:c), coriolis=nothing, momentum_advection=nothing, tracer_advection=nothing)`. **Do not supply :e in the tracers list**: the merged version adds it automatically, and supplying it explicitly raises an error. Set the state with `set!(model, b=0, c=0, e=e₀, u=..., v=0)`; this public entry point updates the closure fields, with no need to call a private kernel. Read the three face fields with `Array(interior(viscosity(model)))`, `Array(interior(diffusivity(model, Val(:c))))`, `Array(interior(diffusivity(model, Val(:e))))`, and obtain the corresponding positions with `znodes(grid, Face())`/`znodes(grid, Center())`. All array indices must match the face/center coordinates.
  Entry-point sources checked: [set!](https://github.com/CliMA/Oceananigans.jl/blob/24de7026893af38df065920fbbf80f05024fd1b9/src/Models/HydrostaticFreeSurfaceModels/set_hydrostatic_free_surface_model.jl), [state update calling the closure computation](https://github.com/CliMA/Oceananigans.jl/blob/24de7026893af38df065920fbbf80f05024fd1b9/src/Models/HydrostaticFreeSurfaceModels/update_hydrostatic_free_surface_model_state.jl). The scheme above is a specification yet to be executed; Julia was not run this time.

  **Item 1.** First read the coefficients from the publicly constructed `closure.mixing_length` and `closure.turbulent_kinetic_energy_equation`, and verify κ_eff⁴D = B⁴a³ and |κ_eff−0.4| ≤ 5×10⁻⁴. To avoid merely repeating the parameter formula, manufacture a state with the independent target κ₀ = 0.4: e₀ = u★²/√(aD), and at each center set U(d) = (u★/κ₀)log(d/d_ref), with d_ref taken as H. At selected interior faces compare the actual ν/(u★d) with 0.4, with absolute error ≤ 5×10⁻⁴; compare νS_h/u★² with 1, allowing a coefficient rounding relative error of 1.25×10⁻³ plus the spatial error. S_h uses the difference of adjacent center velocities divided by the center spacing. Refine with Nz, 2Nz, 4Nz while fixing the physical sampling band, require the derivative error of the logarithmic curve to decrease roughly as O((Δz/d)²) and the final spatial error to be < 10⁻⁴; do not treat the first three cells as fixed physical points. P/ε → 1 can also be checked at the same interior positions, where P = νS_h² and ε uses the dissipation formula independently checked in item 3. This snapshot check tests the constitutive relations and does not claim that the whole column has reached a steady state. The old B = 0.28 should clearly fail the κ≈0.4 check.

  **Item 2.** Take a snapshot with uniform e₀, u=v=0, and compare the three face fields with the explicit branch reference formulas and ratios. Float64 uses `rtol=1e-11`, with absolute tolerance `1e-13 × the maximum of this run's reference field`; this test has no time-integration error, and uniform e eliminates the √e interpolation error. Float32 may use `rtol=1e-5`. To customize the old coefficient, use the publicly documented but unexported `Oceananigans.TurbulenceClosures.TKEBasedVerticalDiffusivities.CATKEMixingLength(Cᵇ=...)` as the constructor argument of `CATKEVerticalDiffusivity(mixing_length=...)`, keeping the other defaults the same. Also take points dominated by the surface limit, where the new and old B should give the same result; take both sides of a branch transition and check continuity with the general min formula, without requiring continuity of the derivative.

  **Item 3.** Use a new model with uniform e₀, u=v=0, import `time_step!` from `Oceananigans.TimeSteppers`, execute one very small Δt and then read `interior(model.tracers.e)`. For each center under test compute R_h = −(e_new−e₀)/Δt and compare with D e₀^(3/2)/(Bd). The default vertical implicit path should still give the same limit as Δt→0; the fact that the private explicit `dissipation` returns zero for the implicit scheme must not be mistaken for physical dissipation being zero. Start Δt at 10⁻³ times the shortest dissipation time Bd/(D√e₀) over all grid centers, subject to Δt·max(Ke)/min(Δz)² ≤ 10⁻³; then halve it successively, each time starting from a new model with the same initial state. Require the relative error to fall below 10⁻³ and show a converging trend; stop before the floating-point subtraction noise starts to grow, and where necessary use linear extrapolation over two adjacent levels. Compare the R_h ratio between the new and old B, and R_h ≥ 0. This method includes the TKE gradient diffusion arising after the finite Δt, but its initial contribution is zero and the error vanishes as Δt→0.

- Formalization (Lean) feasibility: can the invariant be written as a proposition over finite-dimensional reals, and what are the main obstacles:
  **Yes.** Fix one or finitely many grid points, take H,d,e,a,D,B,u★,ν,S,ε as positive reals, and write out the min-branch assumptions and the constitutive relations; from P=ε and νS=u★² prove κ⁴D=B⁴a³ and the proportion relations. Positive-root variables and polynomial equalities can be used to avoid introducing general real powers first, and the three decimals can be treated as rationals with interval bounds used to prove that κ is close to 0.4. The nonnegativity, branch proportions and min continuity of the second item are also suitable for direct proof. The initial continuous-model relation of the third item can be made finite-dimensional as a semi-discrete ODE; if proving the actual Julia update, the main obstacles are the semantic correspondence of face/center interpolation, boundary masks, implicit linear solves, time splitting and floating-point error. A Lean algebraic proof cannot prove that the empirical target 0.4 holds for all real seabeds, nor can it derive from the local equilibrium assumption that the whole water column necessarily converges to that equilibrium.
