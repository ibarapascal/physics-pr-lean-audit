## CliMA/Oceananigans.jl#6024 Fix CATKE's bottom mixing length coefficient Cᵇ
- What changed: The default `Cᵇ` of `CATKEMixingLength` in `src/TurbulenceClosures/.../TKEBasedVerticalDiffusivities/catke_mixing_length.jl` changed from 0.28 to 0.967 (with synchronized docstring and documentation). `Cᵇ` enters `stable_length_scale`: `ℓ = min(Cˢ·depth, Cᵇ·height_above_bottom, ℓᴺ)`.
- Invariants:
  - Primary (parameter algebra): κ_b ≡ Cᵇ·(Cˡᵒu³/CˡᵒD)^{1/4} = 0.40, |κ_b − 0.4| ≤ 1e-3 (default Cˡᵒu=0.361, CˡᵒD=1.604). Comparison: Cˢ gives κ_s ≈ 0.468.
  - Primary (model behavior): In a steady state with neutral stratification (N²=0 ⇒ Ri=0, taking the Ri≥0 branch, with stability functions taking the Cˡᵒ values), no convection, and a constant-stress layer Kᵤ∂_z u = u★², near the bottom (Cᵇ d < Cˢ·depth, and ℓ < H), Kᵤ(z) = κ_b·u★·d, d = height above the bottom; equivalently, ∂_z u = u★/(κ_b d) (log law, κ_b=0.4). Derivation: In the code, Kᵤ = Cˡᵒu ℓ √e, ε = e^{3/2}/ℓᴰ, ℓᴰ = ℓ/CˡᵒD (`ℓ★ = ℓ★ / σᴰ` in `catke_equation.jl`); combining local equilibrium Kᵤ S² = ε with Kᵤ S = u★² gives e = u★²(CˡᵒD/Cˡᵒu)^{1/2}, Kᵤ = ℓ u★ (Cˡᵒu³/CˡᵒD)^{1/4}.
  - Secondary (same expression near the top): Kᵤ = 0.468·u★·depth (unchanged by this PR; used as a control to verify consistency between the derivation and code).
- Sources of the invariants: Literature formula (Wagner et al. 2025, JAMES, doi:10.1029/2024MS004522, §3.1.3 Eq. 35) + first principles (wall similarity law, local TKE equilibrium) + internal library consistency (the derivation above is taken directly from `catke_mixing_length.jl`, `catke_equation.jl`, and `κuᶜᶜᶠ = ℓu·w★` in `catke_vertical_diffusivity.jl` at the merge commit).
- Common operating domain: u★ ∈ [1e-3, 3e-2] m/s (typical friction velocities in ocean bottom boundary layers); water depth H ∈ [50, 5000] m; bottom boundary layer thickness O(10–100 m), checking region d ∈ [2Δz, 0.2·H]; Δz ∈ [1, 10] m.
- Numerical verification method:
  1. Parameter algebra: `using Oceananigans.TurbulenceClosures: CATKEVerticalDiffusivity`; `c = CATKEVerticalDiffusivity()`; compute `c.mixing_length.Cᵇ * (c.mixing_length.Cˡᵒu^3 / c.turbulent_kinetic_energy_equation.CˡᵒD)^(1/4)` and compare with 0.4, with tolerance 1e-3 (the defaults have only 3 significant digits; the actual value is 0.40018).
  2. Halve Δz twice to see whether the result converges to 0.4; this is more robust than a single-point tolerance.

## CoolProp/CoolProp#2851 fix(HEOS): correct first_saturation_deriv for mixtures (#2091)
- What changed: `calc_first_saturation_deriv` in `src/Backends/Helmholtz/HelmholtzEOSMixtureBackend.cpp`. Pure/pseudopure fluids still use the Clapeyron expression dT/dp = T(1/ρ_V − 1/ρ_L)/(h_V − h_L); mixtures now use dT/dp = −Σ_i w_i Δ(∂lnφ_i/∂p)_{T,n} / Σ_i w_i Δ(∂lnφ_i/∂T)_{p,n}, Δ = liquid phase − vapor phase, with w = vapor composition y at Q=0 (bubble-point line), w = liquid composition x at Q=1 (dew-point line), and exceptions thrown for other Q (Gernert's dissertation Eqs. 3.96/3.97). The no-argument overload now delegates to the parameterized version.
- Invariants:
  - Primary A (tangent along the bubble-point/dew-point line): With fixed overall composition z, let p_b(T) be the saturation pressure at Q=0 and p_d(T) the saturation pressure at Q=1. Then `first_saturation_deriv(iT,iP)` at Q=0 = (dp_b/dT)⁻¹, and at Q=1 = (dp_d/dT)⁻¹. Theoretical basis: On the bubble-point line, Σ_i z_i K_i = 1, K_i = φ_i^L/φ_i^V; after total differentiation, the vapor-composition variation term is eliminated by Gibbs–Duhem (Σ_i y_i d lnφ_i^V|_{T,p} = 0), yielding the expression above with weights exactly y_i = z_i K_i; similarly, the weights on the dew-point line are x_i.
  - Primary B (pure-fluid limit): For a binary mixture z = (1−ε, ε), as ε→0, both Q=0 and Q=1 values converge to the Clapeyron value T Δv/Δh of pure component 1, |difference| = O(ε). (Substitute (∂lnφ_i/∂p)_T = v̄_i/(RT) − 1/p, (∂lnφ_i/∂T)_p = −h̄_i^res/(RT²), with weights degenerating to δ_{i1}.)
  - Secondary C (chain derivatives): `first_saturation_deriv(iP,iT)` = 1/`first_saturation_deriv(iT,iP)`; and at Q=0 (the bulk phase is liquid with fixed composition = z), `first_saturation_deriv(iHmolar,iT)` = d h_L/dT along the bubble-point line (at Q=1, vapor h_V along the dew-point line).
- Sources of the invariants: First principles (total differentiation of phase-equilibrium conditions f_i^L = f_i^V along the saturation line + Gibbs–Duhem); literature formulas (Gernert's dissertation 3.96/3.97, cited by the PR); internal library consistency (pure-fluid Clapeyron branch).
- Common operating domain: Methane&Ethane (z_CH4 ∈ [0.1, 0.9], T ∈ [120, 240] K and ≥ 5 K away from the critical point/cricondentherm); also take a refrigerant binary R32&R125 or R32&R1234yf (z ∈ [0.2,0.8], T ∈ [230, 330] K). Near criticality, Σ w_i Δ(∂lnφ/∂T) → 0 and the two phase lines merge; exclude this region. Basis: PR test conditions (0.7/0.3 methane/ethane, 180 K) and common CoolProp refrigerant mixtures.
- Numerical verification method: CoolProp Python low-level interface `AS = CoolProp.AbstractState("HEOS","Methane&Ethane")`, `AS.set_mole_fractions([z,1-z])`, `AS.update(CoolProp.QT_INPUTS, Q, T)`, `AS.first_saturation_deriv(CoolProp.iT, CoolProp.iP)`. A: Create separate states and perform QT flashes at T±h to obtain p, central difference 2h/(p₊−p₋); use h of 0.2, 0.1, 0.05 K for Richardson extrapolation (flash convergence error is approximately 1e-8 relative; too small an h will be overwhelmed by it), for both Q=0 and Q=1, relative tolerance 1e-4 (the PR's self-test uses 5e-3, which is rather loose). B: Use ε of 1e-2, 1e-3, 1e-4, compare with `first_saturation_deriv(iT,iP)` of `AbstractState("HEOS","Methane")` at the same T and Q=0, and check that the difference decreases linearly with ε. C: Compute `first_saturation_deriv(iHmolar,iT)` at the same QT state and compare with the central difference of h(T±h) along the Q=0 line, relative 1e-4. Also verify that Q=0.5 throws an exception.
- Do the PR's own tests already check this invariant: Partially. `src/Tests/CoolProp-Tests.cpp` adds two `[2091]` cases: Methane&Ethane 0.7/0.3, 180 K, Q=0 compared with a dT=0.05 K central difference, relative 5e-3, and dT/dP>0; Q=0.5 throws an exception. Q=1 (dew-point branch), the pure-fluid limit, and chain derivatives are untested.
- Is the change expected to satisfy it: Yes (conjectured). The code expression agrees term by term in weights and signs with the result derived above from Σ z_i K_i = 1. Residual risks (uncertain): The condition uses exact comparison `this->_Q == 0`; if a flash with another input pair (e.g., PQ) stores _Q as a nonzero value of order 1e-16, it would throw incorrectly; the parameterized overload uses the Q of `this` rather than the states of the passed-in SatL/SatV.
- Environment: Merge commit 54a2e32764bfa0ae81877e835c33ccd13ba8f853; C++17 + CMake to build the CoolProp Python extension (or a released wheel after this commit; whether one has been released is unchecked); difficulty medium (source build takes roughly a dozen minutes, with modest memory requirements).
- Formalization (Lean) feasibility: Partially feasible. The final algebraic step (Σ w_i a_i dp + Σ w_i b_i dT = 0 ⇒ dT/dp = −Σwa/Σwb) and pure-fluid limit (reducing to T Δv/Δh when the weights are δ_{i1}, assuming the partial-derivative identities for v̄ and h̄^res) are finite-dimensional real propositions and easy. The core Gibbs–Duhem elimination requires treating lnφ_i as homogeneous functions of (T,p,n) and using Euler's theorem; in Mathlib it can be written assuming “a given derivative matrix satisfying Σ_i n_i ∂_j lnφ_i = 0”; the obstacle is that the specific Helmholtz-energy EOS is not modeled.
